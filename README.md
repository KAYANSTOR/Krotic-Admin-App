# Krotic-Admin-App

لوحة التحكم الإدارية لتطبيق Krotic / NetCard Pro.

تم نسخ المشروع من [NetCardAdmin](https://github.com/KAYANSTOR/NetCardAdmin) للتطوير المستقبلي.

## التشغيل

```bash
npm install
npm run dev
```

## ملاحظات
- انسخ `.env.example` إلى `.env` وأدخل إعدادات Firebase الخاصة بك.
- أيقونات PWA موجودة في `public/icons/` (يمكن إضافتها يدوياً من المستودع الأصلي إذا لزم الأمر).
