# خطة العمل المعتمدة — كروتك

المرجع الأعلى: [`BASELINE_AR.md`](./BASELINE_AR.md). أي قرار أو عقد خارج خط الأساس يُعدّ ملغى.

## قرارات المالك المحسومة (2026-11)
1. **حذف OTP نهائيًا** من التسجيل في التطبيق والخادم واللوحة (مسارات، حقول `phone_verified*`، شاشات، اختبارات).
2. **واتساب على الهاتف فقط**: التطبيق يرسل الكروت من WhatsApp المثبّت (العادي أو الأعمال) كما يرسل SMS، ويستقبل سلفني منه. لا Cloud API ولا QR ولا بوابة خادمية.
3. **العمل دون إنترنت حتى 29 يومًا** (`ENTITLEMENT_MAX_OFFLINE_MS = 29 يومًا`).

## P0 — اللوحة والخادم
| البند | الحالة |

## P1 — تطبيق أندرويد (`feature/paid-features`)
1. حذف OTP ومسار واتساب الخادمي وكل الكود الميت. منجز.
2. إرسال واتساب محلي بإيصال يحدد القناة الفعلية ومفتاح تسليم لكل عملية.
3. نسخ `contracts/schemas` إلى التطبيق واختبارات Dart عليها.
4. بناء APK عبر GitHub Actions وتجربته عند العميل المتأثر.

- مراقبة `activate` و`sales` و`heartbeat` بعد كل نشر.
