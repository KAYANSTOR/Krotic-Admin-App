# خط أساس أداء وقراءات Firestore

**التاريخ:** 2026-10-22  
**الفرع:** `copilot/vscode-mvium5qy-1ydv`  
**الحالة:** أُضيفت أدوات القياس؛ القياس الفعلي من Firebase Console ما زال مطلوباً.

## نطاق القياس

- تعرض اللوحة عند إضافة `?debug=reads` عدّاداً حسب مسار القراءة، وعدد الوثائق المرصودة، ومصدر اللقطة عند توفره (`server` أو `cache`).
- العداد محلي في المتصفح ولا يرسل بيانات إلى أي خدمة.
- الأرقام تقديرية وليست فاتورة Firebase. يجب اعتماد Firebase Console → Firestore → Usage للقراءات المفوترة، خصوصاً للاستعلامات التجميعية وطلبات الخادم باستخدام Firebase Admin SDK.
- تم تغليف استدعاءات Firestore المباشرة في `src/`. لا يشمل العداد قراءات API المنفذة على الخادم.
- لم يُفتح اتصال بقاعدة Firebase ولا تُستخدم بيانات النسخ الاحتياطية في القياس.

## طريقة تسجيل القياسات

1. سجّل قراءة Usage قبل جلسة القياس، ثم افتح اللوحة مع `?debug=reads`.
2. صفّر العداد قبل كل إجراء، وسجّل الرقم الإجمالي وتفصيل المسارات الظاهر في اللوحة.
3. سجّل Usage بعد الجلسة، وكرر الرصد في أوقات استخدام معروفة على مدى ثلاثة أيام.
4. حدّث الجدول أعلاه مع فصل قياس الواجهة عن إجمالي Firebase Usage.
