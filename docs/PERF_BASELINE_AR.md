# خط أساس أداء وقراءات Firestore

**التاريخ:** 2026-10-22 (محدَّث بعد ترحيل الشاشات إلى القاعدة المحلية)  
**الفرع:** `cline/tp5e5bzb` (مبني على `feat/local-first-admin`)  
**الحالة:** أدوات القياس موجودة، والترحيل مكتمل. **القياس المفوتر من Firebase
Console ما زال `Unknown`** ولم أدّعِ أنه جرى.

## نطاق القياس (بصراحة)

- `?debug=reads` يعرض `ReadMeterPanel`: الإجمالي، عدد الاستدعاءات، وتفصيلًا
  بحسب التسمية (`sync:latest:*`, `sync:pull:*`) ومصدر اللقطة إن توفّر.
- العداد محلي في المتصفح ولا يرسل شيئًا إلى أي خدمة.
- **الأرقام أدناه محسوبة من الكود** (عدد المصادر، `PAGE_SIZE = 300`،
  `MIN_AUTO_INTERVAL_MS`، وحدود الاستعلامات) وليست فاتورة Firebase. قراءات
  Firebase Admin SDK من `api/` و`functions/` لا يراها هذا العداد أصلًا، ولا
  تُقاس إلا من Console.
- لم يُفتح اتصال بقاعدة Firebase في هذه البيئة ولا استُخدمت بيانات النسخ
  الاحتياطية في أي قياس.

## خط الأساس بعد الترحيل

| الإجراء | قراءات Firestore (محسوبة من الكود) | قراءات Firebase Usage |
|---|---:|---|
| أول فتح على جهاز جديد | قراءة كاملة مرة واحدة لكل مصدر (10 مصادر) | `Unknown` |
| فتح لوحة المعلومات بعد مزامنة حديثة | 0 | `Unknown` |
| فتح المستخدمين / المبيعات / ملف مستخدم | 0 | `Unknown` |
| التنقل بين أي شاشتين | 0 | `Unknown` |
| زر تحديث/سحب بلا تغييرات | 10 فحوص (`SOURCES.length`) | `Unknown` |
| زر تحديث بعد 5 مبيعات جديدة | 10 فحوص + 5 مستندات | `Unknown` |
| حذف شبكة ثم مزامنة | مستند الشاهد + تطبيق حذف محلي | `Unknown` |

**الفارق عن هدف الخطة:** الهدف كان ≈6 قراءات للفحص، والمنفَّذ 10 (فحص لكل
مجموعة مصدر). التقليل يحتاج مؤشرًا مجمّعًا واحدًا (`sync_meta`) أو دمج الفحوص،
وهو تغيير على عقد المزامنة لم يُنفَّذ في هذه المهمة ولم يُخفَ.

## لماذا صار التنقل صفرًا (دليل قابل للتحقق)

```bash
# لا شاشة تستورد طبقة قراءة Firestore بعد اليوم
grep -rn "lib/adminData" src/            # لا نتائج
grep -rn "onSnapshot" src/               # Layout فقط، بـ limit(1)
grep -rn "getDocs(" src/                 # syncEngine + adminApi (حذف شبكة) + لوحة أجهزة مستخدم
```

## طريقة تسجيل القياسات (للمالك)

1. سجّل `Firestore → Usage → Document reads` قبل الجلسة.
2. افتح اللوحة مع `?debug=reads`، صفّر العداد، ثم: فتح اللوحة ← تنقل بين 8
   صفحات ← زر تحديث بلا تغييرات ← زر تحديث بعد 5 مبيعات.
3. سجّل بعد كل خطوة: رقم العداد + رقم Console.
4. كرّر على مدى ثلاثة أيام واستخدم أوقات استخدام معروفة لتقسيم الاستهلاك.
5. حدّث الجدول أعلاه، وافصل دائمًا «قراءات الواجهة» عن «إجمالي Firebase
   Usage» (يشمل الخادم والدوال).
